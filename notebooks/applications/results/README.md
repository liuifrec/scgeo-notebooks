# Results-first public applications

Explore actual ScGeo 0.2.1 biological outputs without downloading the original data or installing ScGeo. Browse unchanged native ScGeo PlotResult exports for all three datasets alongside the existing B/C aggregate molecular galleries. Native viewers verify and display the actual images; aggregate viewers recalculate summaries from compact snapshots.

| Dataset | Design and inference scope | Result notebook | Illustrated gallery |
|---|---|---|---|
| GSE249479 — human HSPC inflammation | 34,432 retained cells, 14 pooled state-contrast explanations; biological replicate identities unavailable | [TNF versus LPS](gse249479/GSE249479_inflammation_results.ipynb) | [Five aggregate figures](gse249479/README.md) · [Native outputs](gse249479/native/README.md) |
| GSE211713 — mouse-lung radiation | 131,157 retained cells, 27 state-contrast explanations; three cross-sectional contrasts of 13 qualified primary-roster mice | [Fibroblast responses](gse211713/GSE211713_fibroblast_results.ipynb) | [Six aggregate figures](gse211713/README.md) · [Native outputs](gse211713/native/README.md) |
| GSE280305 — mouse hematopoietic recovery after irradiation | 31,605 retained cells, 14 clusters; D8–D21 descriptive comparison | [Native results notebook](gse280305/GSE280305_native_results.ipynb) | [Eleven native figures](gse280305/README.md) |

All three applications use their verified original linear representation. None of the galleries represents cell trajectories, causal regulation or independently validated predictors. Retrospectively selected molecular examples are not confirmatory tests. The complete [geometry and molecular analysis notebooks](../v0.2.0/README.md) are separately reproducible with the original inputs. The compact results-first notebooks are designed for immediate browsing and lightweight execution.
