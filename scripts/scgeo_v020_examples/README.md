# ScGeo 0.2.0 example snapshots

The 13 upstream Python examples are copied without modification from
https://github.com/liuifrec/scgeo/tree/46ba9017ceef17255292edd0140602ed13ac5305/examples
(MIT; see the repository LICENSE). SOURCE_PART1.json and SOURCE_PART2.json
record the upstream paths and Git blob hashes. `tutorial_support.py` is new
companion-side infrastructure, not part of those snapshots. The public-data
and source-preflight scripts have explicit input requirements. See the
[notebook learning track](../../notebooks/tutorials/v0.2.0/README.md).
