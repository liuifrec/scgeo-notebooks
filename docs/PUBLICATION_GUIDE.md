## Report the analysis you actually ran

Record the following with a Methods section, supplementary protocol, or public
analysis repository:

| Item | What to record |
|---|---|
| Software | ScGeo version and exact package commit/tag when applicable |
| Workflow | Exact `scgeo-notebooks` commit, notebook path, and configuration files |
| Data | Dataset accessions, processed-object provenance, and input checksums |
| Design | Conditions, contrasts, state labels, biological sample unit, and available replication |
| Geometry | Quantitative representations, primary/sensitivity roles, estimator, and relevant parameters |
| Uncertainty | Resampling/permutation unit and settings; descriptive scope when valid sample identity is unavailable |
| Outputs | Source tables, execution/version records, and output checksums |
| Adaptations | Changes to preprocessing, parameters, annotations, code, or presentation |

## Credit the underlying data and methods

When reusing a public dataset, cite its originating study and accession as well
as ScGeo. When your analysis uses Scanpy, scVelo, CellRank, an integration or
representation-learning method, or the official R Augur comparator, cite the
relevant original methods according to what you actually used. The
[workflow catalog](DATASET_MAP.md) identifies the datasets and the role of each
validation workflow.

Keep the distinction between official R Augur and the retained Augur-inspired
Python approximation explicit. Likewise, a processed public pancreas workflow
has its own acquisition provenance; report that input rather than implying an
independent reconstruction from raw GEO files.

## Preserve the scope of the evidence

For an adapted study, describe the inference supported by its own design.
Independent samples support sample-aware uncertainty; cells or artificial
partitions do not become biological replicates. Related PCA dimensions share a
basis, and agreement between representations or with a dynamics estimate is
conditional on those models and their assumptions.

The companion's GSE249479 conclusions remain descriptive. GSE211713 uses
independent mice in a cross-sectional design and does not establish within-mouse
change or causality. The [results guide](RESULTS_OVERVIEW.md) preserves the
accepted findings and their limitations for accurate reuse.

## Reuse of code and figures

The repository code is distributed under the [MIT license](../LICENSE);
retain applicable license notices when reusing
code. Check the originating article, dataset, and figure licenses separately
for material that is not covered by the code license, including third-party
illustrations.

When adapting a figure generated by these workflows, retain its source-table
provenance, identify the original study, and state what you changed. Preserve
negative findings and uncertainty alongside the highlighted result.

The [development plotting workflow](PLOTTING_WORKFLOWS.md) can redraw archived
tables with recorded input hashes and exported source values. Keep sample
bootstrap intervals distinct from representation quartiles, and report the
metric's coordinate system when comparing contrasts.
